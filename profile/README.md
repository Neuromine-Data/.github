# Neuromine

Neuromine is the data team behind Answer ALS and ALS TDI. This organization holds the parts of that work that anyone may reuse: shared tools for making consistent, on-brand outputs and the methods behind published data, so readers can see and repeat how the data were made.

## Repositories

- [aals-atac-seq-pipeline](https://github.com/Neuromine-Data/aals-atac-seq-pipeline) - Unmodified copy of the ENCODE ATAC-seq pipeline used for Answer ALS epigenomics data.
- [aals-leafcutter-pipeline](https://github.com/Neuromine-Data/aals-leafcutter-pipeline) - Answer ALS motor neuron RNA-seq splicing quantification with LeafCutter.
- [aals-rna-seq-pipeline](https://github.com/Neuromine-Data/aals-rna-seq-pipeline) - Answer ALS RNA-seq processing pipeline with pinned software, reference provenance checks and documented validation.
- [aals-standardized-omop-etl](https://github.com/Neuromine-Data/aals-standardized-omop-etl) - ETL pipeline mapping Answer ALS clinical data to OMOP CDM 5.4, with source provenance.
- [brand-skill](https://github.com/Neuromine-Data/brand-skill) - Brand rules, templates and checkers AI agents use for Neuromine documents, decks and sheets.
